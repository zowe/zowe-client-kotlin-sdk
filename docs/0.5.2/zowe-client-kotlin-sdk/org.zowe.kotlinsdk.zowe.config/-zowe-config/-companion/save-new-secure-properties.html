saveNewSecureProperties

fun saveNewSecureProperties(origFilePath: String, configCredentialsMap: MutableMap<String, Any?>, keytar: KeytarWrapper = DefaultKeytarWrapper())

Save secure object configCredentialsMap for provided file in credential object and save these changes to credential storage.

Return

Nothing.

Parameters

origFilePath

path of zowe.config.json file. Secure props will be saved inside this property of connection object.

configCredentialsMap

map with parameters and values to save in credential storage. Ex. "profiles.base.properties.user" = username

keytar

instance of KeytarWrapper. This param is needed for accessing credential storage.
