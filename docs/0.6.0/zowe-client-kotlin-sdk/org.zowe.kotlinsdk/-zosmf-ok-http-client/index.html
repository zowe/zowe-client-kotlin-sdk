ZosmfOkHttpClient

object ZosmfOkHttpClient

Provides the OkHttpClient instances the SDK client classes use to talk to z/OSMF.

By default, the client validates the server certificate chain against the JVM trust store and verifies the host name. Certificate validation is skipped only when the caller explicitly asks for it by setting ZOSConnection.rejectUnauthorized to false.
